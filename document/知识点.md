# 一、串口（UART/RS232）和 RS485 基础参数
 
> 这里说的串口配置：**波特率、数据位、停止位、校验位**，属于 **UART 链路层协议参数**，RS232、RS485 都可以跑这套 UART 通信，只是**物理层电平不一样**。

1. **波特率 Baudrate**：每秒传输符号（bit）数量，常见：9600、19200、38400、115200。
注意：波特率 ≠ 有效数据速率，包含起始位、停止位、校验位开销。
2. **数据位 Data bits**：一帧里真正的数据比特，一般 8bit（最常用），也有 7bit。
3. **停止位 Stop bits**：一帧结束的标记，1bit（常用）、1.5bit、2bit。
4. **校验位 Parity**：检错用
   - None：无校验（工业最常用）
   - Odd：奇校验
   - Even：偶校验
   - Mark：固定 1
   - Space：固定 0

> 
> 一句话区分：**UART 是通信逻辑帧规则；RS232 / RS485 是不同的电平物理标准**。同一个串口程序，换收发芯片就能从 RS232 改成 RS485。
